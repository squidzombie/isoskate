===== ORCHESTRATOR NOTES FOR GATE G1 (read before the hand-offs) =====
These come from the orchestrator, who read every P3 hand-off and review. Decisions here are final unless the evidence proves them wrong (then say so in the report).

1. MACHINE LOAD. Every package saw real-time e2e tests (touch.spec / smoke.spec desktop, audio.spec cost) fail while 4 agents shared 4 cores (load 8-17), and pass when re-run alone. At G1 you are the only heavy process: run the full e2e once quietly before judging; if a real-time test still fails, find out whether the code or the test is wrong (do not just raise timeouts). Make sure no stray vite/chromium processes from earlier agents are running (ps) before measuring.

2. BUNDLE SIZE. WA alone is 319 KB gzip, WA+WG 354 KB (M0 was 268), MU adds ~28 KB, GP some more: expect ~390 KB against the 350 KB budget (TECH §8.4 / §11.6, enforced from M4). Debug code and bots are already excluded from the production bundle. At G1: report the exact number and the top contributors (e.g. with a quick rollup-plugin-visualizer-free method: build with sourcemaps and sum bytes per source folder from the map). Do cheap safe wins only (dead code, duplicated tables, unused three imports); the M4 performance pass owns the rest. DECISION: if after M4 trimming the honest total is still above 350 KB, the budget becomes 420 KB gzip JS+CSS (fonts excluded); a ~400 KB game loads in about a second on 4G and the PWA caches it; record this in TECH §8.4 as a design decision row. Do not ship visible quality cuts to meet 350.

WG passes the mounting height in Decor.y (sidewalk + 2.4-3 m for awnings, blade signs, banners); WA adds its own mounting height again, so in the merged game awnings float at ~5.9 m. Resolve with ONE definition in core/decor.ts docs + TECH §4.14 (recommended: Decor.y = the base height of the surface the decor stands on or hangs from (ground/sidewalk/wall foot), and each kind's documented params give its own mounting height; or the opposite, but exactly one), then fix whichever side disagrees.
